# image

Image display with responsive sizing.

- **src**: string - Image URL or local path
- **alt**: string (optional) - Accessibility text
- **fit**: `"cover" | "contain" | "fill"` - Image fit mode
- **width**: number (optional)
- **height**: number (optional)

```jsx
<image src="https://example.com/photo.jpg" fit="cover" width={200} height={200} />
```
